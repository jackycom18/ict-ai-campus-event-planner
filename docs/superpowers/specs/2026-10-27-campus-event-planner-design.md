# AI 校园活动策划团队设计

## 目标

为“计算机学院 2026 级篮球迎新杯”建立可复用的多 Agent 活动策划流程，并生成可直接提交的 HTML 方案、预算 XLSX、风险 XLSX、宣传 PPTX、对话记录和 README。

## 活动输入

- 活动名称：计算机学院 2026 级篮球迎新杯
- 主办方：计算机学院学生会
- 时间：2026 年 11 月 14 日 09:00-17:30
- 地点：深圳技术大学南区篮球场
- 规模：8 支队伍，约 120 名新生及工作人员
- 预算上限：30,000 元
- 目标：促进新生交流，完成学院迎新文化展示

## Agent Team

| 角色 | 单一职责 | 产物 |
|---|---|---|
| Leader | 任务分解、依赖检查、最终汇总 | 执行状态与交接记录 |
| 策划分析师 | 活动流程、赛制、人员安排 | 活动方案 |
| 预算分析师 | 收入支出与预算余量 | 预算工作簿 |
| 风险管理员 | 风险识别、等级、预案 | 风险工作簿 |
| 宣传文案师 | 主题、文案、传播节奏 | 宣传内容 |
| 文档设计师 | HTML 整合与 PPTX 视觉表达 | 最终展示件 |

## 数据流

```text
event-brief.json
  → 策划 / 预算 / 风险 / 宣传 Agent
  → 结构化 output JSON
  → HTML、XLSX、XLSX、PPTX 生成器
  → 归档目录 + 自动化验证
```

## 视觉方向

主题为“篮下开场”，使用球场记分牌和纸质赛事手册的混合语言：

- 深墨绿：`#102A2A`
- 球场地板橙：`#D86D38`
- 记分牌米白：`#F2EBDD`
- 电子青：`#35B7A0`
- 警示红：`#B93C35`

标题使用 `Bahnschrift Condensed`，正文使用 `Microsoft YaHei UI`。HTML 采用非对称赛事手册布局；PPTX 以球场中线和记分牌数字为视觉线索，不使用通用卡片网格。

## 交付结构

```text
Agent办公实践AI校园活动策划团队实践作品/
├─ Agent办公实践AI校园活动策划团队实践.md
├─ readme.md
├─ 校园篮球迎新杯活动策划方案.html
├─ 预算测算表.xlsx
├─ 风险评估预案.xlsx
└─ 校园篮球迎新杯宣传方案.pptx
```

## 验收

- HTML 包含活动流程、赛制、人员、预算摘要、风险和宣传内容。
- 预算表总额不超过 30,000 元并包含公式。
- 风险表至少包含 10 项风险、等级和预案。
- PPTX 至少 6 页，文本可编辑且无溢出。
- 归档目录包含 6 个指定文件。
- 自动化验证全部通过。
- 全程零云费用。
