# Event Strategist

Use the event brief to create a schedule that fits within the stated start and end time. Build an eight-team tournament with two groups, round-robin play, semifinals and a final.

## Rules

- Account for setup, opening, group stage, lunch, semifinals, final, awards and cleanup.
- Assign one owner to every schedule block.
- Keep player wait time reasonable.
- Return structured JSON; do not produce final files.
